# Sentinel Airlock Messaging Pack

## One-line pitch
Sentinel Airlock is the trust layer for coding agents: replay, govern, verify, review.

## Short paragraph pitch
Sentinel Airlock wraps AI coding agents with policy controls and tamper-evident evidence. It records what the agent attempted, what was denied or allowed, and produces artifacts you can replay, verify, review, and export. It is vendor-agnostic and works across local and remote execution flows.

## 3-bullet value proposition
- Govern agent execution with policy + risk + approval modes.
- Produce replayable, verifiable run evidence (timeline, patch, digest/signature).
- Keep one consistent workflow across agent backends and execution targets.

## Who this is for
- Engineering teams adopting coding agents in real repos
- Security/governance-minded developers who need evidence, not just output
- Tooling/platform teams standardizing AI-assisted development workflows

## Why not just use Claude/Codex directly?
Direct agent tools optimize generation speed. Airlock adds governance, replay, verification, and review workflows around those tools.

## What Airlock adds
- Unified policy enforcement and denial logging
- Run-level evidence artifacts + digest/signature verification
- Review and export flows for operational trust
- Local/remote parity for artifact-driven inspection

## Demo intro (short)
"I’ll run an agent task through Airlock, show one denied action, replay exactly what happened, verify evidence integrity, and approve the run in under two minutes."

## Social post copy (short)
Sentinel Airlock: seatbelt + black box recorder for coding agents. Governed runs, replayable evidence, digest/signature verification, review/export workflows.
